GRIPSHOLMS REDOVISNING AB
Nytt designförslag, 7 oktober 2026.

HEMSIDAN
index.html är hela hemsidan. Bilder, typsnitt, stilar och funktioner ligger inbäddade i filen. Den fungerar även när du öppnar filen direkt på datorn.

GITHUB PAGES
Lägg index.html direkt i rotmappen för ditt GitHub-repository. Behåll gärna licensfilerna tillsammans med den. Aktivera GitHub Pages för den grenen och rotmappen. Inget byggsteg behövs.

FUNKTIONER
Mobilmeny, utfällbara tjänster, vanliga frågor, ringlänkar, kartlänk, mejlruta och kopiering av mejladress i webbläsare som tillåter det. Mejl skickas genom besökarens eget mejlprogram. Inget kontaktformulär eller externa spårningsskript.

UTÖKAT INNEHÅLL
Utvecklade tjänstebeskrivningar, en sektion om det första samtalet och fler frågor om arbetsfördelning, byte av redovisningshjälp och pris. Sofia Tappers roll som VD är verifierad i företagsuppgifter. Förberedelserna beskriver förslag på samtalsämnen, inte ett löfte om ett visst arbetssätt eller tillgänglighet.

OM FÖRSLAGET
Ingen officiell hemsida eller grafisk profil kunde verifieras. Logotyp, färger och texter är därför ett nytt förslag. Kontaktuppgifter och allmän verksamhetsbeskrivning kommer från offentliga företagsuppgifter. Företaget bör kontrollera kontaktuppgifter och tjänstetext inför publicering. Inga kundomdömen, auktorisationer, samarbeten eller prisuppgifter har hittats på.
